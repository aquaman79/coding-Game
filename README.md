# 📊 Complexity

For every problem, I aim to understand:

```text
Time Complexity
Space Complexity
```

Examples:

```text
O(1)       Constant
O(log n)   Logarithmic
O(n)       Linear
O(n log n) Linearithmic
O(n²)      Quadratic
```

The goal is not only to make the solution work, but to understand **why the solution has a particular complexity** and whether it can be improved.

# 🎯 Learning Strategy

For each problem:

```text
1. Understand the problem
        ↓
2. Find the pattern
        ↓
3. Think about the data structure
        ↓
4. Implement the solution
        ↓
5. Test edge cases
        ↓
6. Analyze Time & Space Complexity
        ↓
7. Refactor / Improve
```
