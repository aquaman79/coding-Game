# 📊 Complexity

For every problem, I aim to understand:

```text
Time Complexity
Space Complexity
```

Examples:

```text
O(1)       Constant
O(log n)   Logarithmic
O(n)       Linear
O(n log n) Linearithmic
O(n²)      Quadratic
```

The goal is not only to make the solution work, but to understand **why the solution has a particular complexity** and whether it can be improved.

For example:

```text
Binary Search
Time: O(log n)
Space: O(1)

Maximum Subarray
Time: O(n)
Space: O(1)

Product of Array Except Self
Time: O(n)
Space: O(n) with prefix/suffix arrays
```

# 🎯 Learning Strategy

For each problem:

```text
1. Understand the problem
        ↓
2. Identify the pattern
        ↓
3. Choose the right data structure
        ↓
4. Think about a brute-force solution
        ↓
5. Improve the complexity
        ↓
6. Implement the solution
        ↓
7. Test edge cases
        ↓
8. Analyze Time & Space Complexity
        ↓
9. Refactor / Improve
```

The objective is to avoid memorizing solutions and instead understand **why an algorithm works**.
